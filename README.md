# Application Ascenseur Control

Outil FR/NL hors-ligne qui transforme un rapport de visite ou une analyse de risques ascenseur en tableau de remarques : explication, solution, code, contrôles, export Word/Excel.

**Ouvrir l'application :** https://mbbouazza1975-sys.github.io/ascenseur-control/

- Fonctionne entièrement dans le navigateur : aucun rapport n'est envoyé sur internet, aucune IA.
- Première utilisation : charger le fichier Excel officiel des codes (lien « Charger le fichier des codes »). La liste n'est pas publiée ici ; elle reste dans le navigateur de chaque utilisateur.
- Les PDF scannés ne sont pas lus : coller le texte ou demander la version numérique.
- Chaque tableau doit être relu par l'ingénieur avant envoi au client.
